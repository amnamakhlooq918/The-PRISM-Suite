The PRISM Suite
Refracting Data into Results
## 🌟 Overview
The PRISM Suite is a high-performance administrative automation tool designed to streamline student data management. Developed with a focus on precision and user experience, it transforms the manual, error-prone tasks of data handling into a seamless, "one-click" professional workflow.

Originally created for school Control Teams, this suite bridges the gap between complex data architecture and intuitive administrative needs.

🚀 Key Features
The Smart Splitter: Instantly refracts massive master files into organized, class-specific workbooks.

The Smart Merger: Consolidates decentralized teacher records back into a single, structured report with zero data loss.

Dynamic Pathing: Fully customizable output locations—the user chooses exactly where the results are saved.

Custom Naming: Direct control over file nomenclature to match institutional filing standards.

Premium UI: A custom-built interface that hides the traditional Excel grid to provide a "Standalone App" experience.

🛠️ Technical Specifications
Core Engine: VBA (Visual Basic for Applications)

File Format: .xlsb (Excel Binary Workbook) for optimized speed and reduced file size.

Compatibility: Optimized for Microsoft Excel for Windows.

📥 Getting Started
Download: Save the The_Prism_Suite.xlsb and the User_Documentation.pdf to your local drive.

Enable Macros: Upon opening the file, click "Enable Content" at the top of the screen to activate the automation logic.

Run: Use the central dashboard to begin your splitting or merging tasks.
